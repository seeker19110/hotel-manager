# VietQR — cấu trúc chuỗi (xác minh 2026-10-15)

Phục vụ SPEC-ledger-payments S-015 (`payment.getTransferInfo`). QR chỉ là **thông tin** chuyển tiền; không ghi tiền.

## Kết luận dùng trong code (`packages/domain/src/payments/vietqr.ts`)
- TLV `ID(2) + độ dài(2) + giá trị`; trường dùng: `00`=`01`; `01`=`11` tĩnh / `12` động; `38` = { `00` GUID `A000000727`, `01` = { `00` BIN 6 số, `01` số TK }, `02` `QRIBFTTA` }; `53`=`704`; `54` số tiền nguyên đồng; `58`=`VN`; `62` = { `08` nội dung CK }; `63` CRC.
- CRC-16/CCITT-FALSE (poly 0x1021, init 0xFFFF), tính trên toàn chuỗi tới hết `6304`; 4 hex HOA. Check value "123456789" → `29B1`.
- Test vector (CRC tự tính lại khớp): `…970423…0123456789…QRIBFTTA…5406150000…0808DH123456…6304` → `79AB`; tĩnh `…970407…9602091996…` → `34A0`; `…970436…1017595600…0819thanh toan don hang…` → `70FA`.
- BIN (api.vietqr.io/v2/banks, curl trực tiếp): VCB 970436 · TCB 970407 · MB 970422 · VPB 970432 · ACB 970416 · BIDV 970418 · ICB (VietinBank) 970415.

## (chưa xác minh)
- Văn bản NAPAS QR Format T&C v1.5.2 gốc và EMVCo QRCPS-MPM v1.1 gốc: không tải được ngày 2026-10-15.
- Tag 59/60/52 có bắt buộc với `QRIBFTTA` không; giới hạn độ dài/ký tự của 62.08 (dịch vụ khác nhau nói 23 và 50) → code giới hạn chặt `[A-Z0-9 ]{1,25}`, chỉ dùng mã tham chiếu 8 ký tự.
- Trước khi phát hành (G7): đối chiếu với văn bản NAPAS gốc hoặc quét thử bằng ứng dụng ngân hàng thật (điểm dừng: không dùng tài khoản thật khi chưa duyệt).
